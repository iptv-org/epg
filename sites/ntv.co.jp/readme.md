# ntv.co.jp

https://www.ntv.co.jp/program/

### Download the guide

```sh
npm run grab --- --sites=ntv.co.jp
```

### Update channel list

```sh
npm run channels:parse --- --config=./sites/ntv.co.jp/ntv.co.jp.config.js --output=./sites/ntv.co.jp/ntv.co.jp.channels.xml
```

### Test

```sh
npm test --- ntv.co.jp
```
